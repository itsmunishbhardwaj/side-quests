# Anshika's Internship Calendar

182-day internship journal · May 22 – Nov 19, 2026

## Deploy to GitHub Pages (phone access)

1. Create a new repo on GitHub (e.g. `anshika-internship`) — set it to **Public**
2. In this folder, run:
   ```bash
   git init
   git add .
   git commit -m "init internship calendar"
   git remote add origin https://github.com/YOUR_USERNAME/anshika-internship.git
   git push -u origin main
   ```
3. Go to the repo on GitHub → **Settings** → **Pages** → Source: `Deploy from a branch` → Branch: `main` / `/ (root)` → Save
4. Your site will be live at:
   ```
   https://YOUR_USERNAME.github.io/anshika-internship/
   ```
   (takes ~1 minute to go live the first time)

## Data

- All logs are saved in your **browser's localStorage** — they persist across app closes and phone restarts as long as you don't clear browser data.
- Use **Export Backup** regularly to download a `internship-logs-backup.json` file.
- Use **Import Backup** to restore from that file if needed.

> The site URL stays the same forever — bookmark it on your phone home screen.
